## 1. 执行规则

- 先关闭设计矛盾，再测试技术假设。测试结果不能替代黑名单语义、冷启动去向和上下文降档语义的选择。
- 以发布构建验证；开发热更新、DevTools 长期开启和特殊浏览器启动参数的结果单独标识。
- 先使用本地模拟服务和合成秘密；公司网络测试只需要脱敏结果，不记录真实 Key、完整私有页面或请求头秘密。
- Chrome 与 Edge 分别记录结果。若继续承诺 141 起支持，要有对应版本证据；否则调整最低版本说明。
- 每个用例状态只能是：未执行、通过、失败、环境阻塞、接受降级。接受降级必须附产品行为变化，不能涂成通过。
- 保留测试壳、固定样本、日志和结论。可丢弃临时实现，不丢弃验证资产。
- 性能目标沿用架构初值作对比，不在没有数据时提高或降低要求。数值最终由原型校准后回写需求。

## 3. 核心原型门槛

### V-01：真实网络链路与后台生命周期

**对应：** AR-03、04、25；原架构原型 1、8。

**模拟服务至少提供：**

- 立即返回响应头并正常 SSE 输出。
- 等待 35 秒、65 秒才返回响应头。
- 立即返回头，但 65 秒没有正文增量。
- 持续输出超过五分钟。
- 长时间等待后返回非流式 JSON。
- SSE 注释心跳、不同换行、一个事件跨多个网络块。
- 流中报错、突然断开、200 HTML、401/403、404/405、参数 400。

**步骤：** 分别在小窗显示、隐藏、转侧边栏、关闭源标签页、无 UI 订阅、后台休眠后触发、系统休眠恢复时执行。再在公司 WiFi / UniVPN 的真实中转站验证最小对话。

**通过条件：** 知道请求是否到达服务端；能区分响应头和首条内容时间；状态正确；中断不丢已确认检查点；无自动重复请求。公司网络至少实际收到一次有效模型响应。

**失败退路：** 能力与环境明确受限时显示原因；重新评估执行环境并修订权限。不能用“安装成功”“端口可达”或“切非流式”替代证明。

**证据：** 浏览器版本、是否开 DevTools、网络环境、模拟模式、接单次数、时间线、任务终态与脱敏错误。

### V-02：无预热入口与降级路由

**对应：** AR-02、19、22；原型 2、10。

**步骤：** 全新标签页立即选词并点击；后台已休眠；快捷键直接唤起；右键总结；模拟 iframe 加载失败、延迟和握手失败；点击时准备状态仍 unknown。

**通过条件：** 每次只开一个目标界面；没有吞掉问题或重复发送；落到侧边栏时提示准确，不把“尚未就绪”误说成“网站不支持”；操作数符合最终选定契约。

**失败退路：** 在用户交互时同步去侧边栏，或记录需要额外操作的已接受降级。不能等待异步失败后假定还保有激活。

**证据：** 用户动作到 UI、到请求的时间线；冷态/暖态分开；失败缓存的作用域、过期和重试行为。

### V-03：后台恢复、并发与幂等

**对应：** AR-04、07、17。

**步骤：** 接单后断端口；发相同 requestId 两次；快照后注入旧增量；两个界面同一对话同时发送；停止和完成竞争；在检查点间隔中终止后台后重新打开。

**通过条件：** 同一请求不重复接单；内容不重复拼接；终态稳定；恢复后中断清楚可见；新选区不改变在途请求；重试有新 attemptId 和可见语义。

**失败退路：** 缺少确认时不偷偷重发，提供可辨认的重试入口；恢复只保证保存内容和状态，不宣称恢复同一网络流。

### V-04：权限、黑名单与敏感输入

**对应：** AR-01、07、14、18。

**组合：** 无限制 / 不弹工具栏 / 不读取；新页 / 已开页 / 子框架；工具栏 / 右键 / 快捷键 / 已开侧边栏 / 辅助建议。

**输入样本：** 密码框、普通 input、textarea、contenteditable、只读代码 textarea；页面与子框架采用不同策略。

**通过条件：** 被禁止内容从抽取、缓存、请求和日志各层都不可见；修改禁止读取后立即拦截新的发送；页面更新不会把旧缓存作为旁路；只读代码例外不扩散成所有输入例外。

**证据：** 模拟服务收到的完整合成请求、脚本注册状态、待发任务取消结果、缓存失效记录。只展示 UI 的“已关闭”不是证据。

### V-05：IPC 授权与 iframe 边界

**对应：** AR-05、18；原型 14、15。

**步骤：** 使用错误 tab/frame/document、过期或重复令牌、错误 conversationId、超大消息；普通网页自行嵌入 float 页面；导航前后重放消息；检查秘密存储启动窗口。

**通过条件：** 未授权请求被拒绝且无写入/网络副作用；握手前无历史数据；私有端口只路由到目标阅读器；内容脚本不能读取 Key。

**待实测边界：** use_dynamic_url 的资源加载、sender 身份、Edge 行为、宿主遮挡/移除 iframe。能够阻止未授权嵌入不等于已证明全面防点击劫持。

### V-06：页面身份与缓存失效

**对应：** AR-06、07、15。

**步骤：** 保持 URL、main 节点和长度不变替换文本；hash 路由；查询参数切换；前进/后退恢复；同 URL 双标签页不同内容；在模型回答前导航；旧总结再次打开。

**通过条件：** 新请求使用正确版本；旧回答仍归属原版本；旧总结有准确标注；不会把旧锚点应用到无关新文档。

**失败退路：** 不确定时重新读取、显式显示旧快照；不可用“长度一致”判内容一致。

### V-07：请求装配与预算

**对应：** AR-07、08、09。

**样本：** 中文、英文、代码、表格、公式、长历史；不同上下文窗口；全文→选中；连接切换；自定义 JSON 含受保护字段；能力未知。

**通过条件：** 完整请求与有效 UI 设置一致；输出预算已预留；截断范围和覆盖率可重算；降档移除旧全文；模型实际标识正确；一次连接学到的怪癖不影响另一连接。

**失败退路：** 可见缩减上下文或更换模型；不静默超量、换模型或改变思考语义。

### V-08：PageDoc 与正文质量

**对应：** AR-13、14、21；原型 3、5、7。

**样本集：** 20–30 个去敏的真实页面，覆盖中文文章、技术文档、GitHub、文献页、长代码、表格、公式、折叠标签页、重复布局、跨源 iframe。额外保留反例样本，不只用效果好的网页。

**比较：** 自研根节点/块抽取、成熟库辅助正文识别、可行的映射方案；相同输入、相同质量指标。

**通过条件：** 选区和答案证据被保留；前后段落语义正确；不读输入值；能描述漏读边界；对 1927/1934 等远处指代有可测的召回结果。

**证据：** 人工标出的关键证据块、抽取文本、映射、耗时、噪声比例和错误分类。自研不是预先指定的胜者。

### V-09：引用与总结锚点

**对应：** AR-15、21；原型 4。

**步骤：** 响应前插入/删除段落；重复同一句；模型输出无效块号；快照 7 天过期；多框架引用；精确、近似和失败定位。

**通过条件：** 只接受发送块集合内的编号；定位到正确文档/版本；不确定时降级并解释，不假装精确高亮；无法匹配时不可点击。核心只做块编号也要通过版本绑定检查。

**质量评估：** “能找到位置”和“该位置支持回答结论”分别计分。

### V-10：安全渲染与流式语法

**对应：** AR-11、12。

**输入：** 原始 HTML、危险协议、引用标记中的属性字符、后置 Markdown 引用定义、嵌套列表、表格、未闭合代码/公式、巨大公式、超长代码、KaTeX 错误和宏输入。

**步骤：** 每个样本按不同 chunk 边界输入；用户生成中选中文本、复制、滚动、停止。

**通过条件：** 不执行不可信代码、不自动请求外链；最终结果与规定语法的完整渲染一致；状态可操作；稳定块不被无故替换；用户选区和阅读位置得到约定保护。

### V-11：侧边栏与小窗转接

**对应：** AR-02、19、23；原型 10、13。

**组合：** Chrome/Edge；最低支持版/目标稳定版；一个/两个窗口；面板关闭/打开/切到其他面板；后台冷/热。

**步骤：** 快捷键快速触发两次；打开期间切标签页；流式中从小窗转接；转接时关闭小窗；侧边栏先完成连接而 handoff 尚未到达。

**通过条件：** 无闪开闪关、错窗关闭、订阅错误会话、重复答案或失去问题；转接成功后再隐藏原界面；支持范围和降级文案与实际一致。

### V-12：交互和无障碍

**对应：** AR-23；原型 2、11、12。

**步骤：** 键盘选区、Tab/Shift+Tab、中文输入法组合输入、Esc、复制代码；宿主原生 dialog 打开；200% 缩放；侧边栏开合引起重排；生成中继续阅读/选词。

**通过条件：** 焦点可见且不被异步结果夺走；中文确认键不误发送；关闭不丢草稿；返回阅读位置可预期；不能使用时提示和退路明确。

### V-13：性能与资源

**对应：** AR-20；原型 2、6、9。

**基线：** 同一设备、同一浏览器版本、同一页面，扩展禁用与启用对照。

**场景：** 无交互页面、划词未点击、冷/暖启动、大页面、多框架、连续滚动、长回答、30 个标签页分别使用后隐藏。

**记录：** 包体积、加载主线程时间、长任务、p50/p95 操作延迟、首个有用回答时间、内存峰值与回落、后台唤醒次数、跨消息传输字节、模型调用次数。

**通过条件：** 以原架构目标为初始对照，结合实测形成被接受的阈值；空闲页不做正文抽取；只选词未提问不调用模型；隐藏资源能按预算回收。全部数字注明测量环境，不能从 gzip 推导内存。

## 4. 相应模块发布前的门槛

### V-14：收藏、数据库、更新与恢复

**对应：** AR-17、22、26。

**步骤：** 写失败、空间不足、删除对话/收藏、blob 引用清理、快照过期；旧 schema 升级；加载解压缩原目录更新；扩展重载；JSON 设置导入；若实现完整备份则另测完整恢复。

**通过条件：** “已存”对应成功写入；删除及过期规则完整；升级失败不悄悄损坏数据；导出在实际恢复测试中可用。设置备份与完整数据备份不混称。

**范围：** 核心持久化的恢复先测；完整收藏、搜索与导出按产品分期进入。

### V-15：截图和页面图片

**对应：** AR-10、16、18。

**步骤：** 框选后切页/切窗/滚动/缩放；侧边栏重排；不同系统 DPI；遮罩和小窗存在；取消；页面图片跨源、需登录、很大或不可读。

**通过条件：** 图片属于发起页面和版本、坐标正确；发生竞争时丢弃，不误发；预览后明确提交；图片获取路径和模型接收方可审查；无模型秘密被发给图片域名。

### V-16：联网搜索与更新检查

**对应：** AR-10、21、25、26。

**步骤：** 搜索开关关闭；逐条联网按钮；搜索查询包含敏感合成信息；搜索结果指向内网、重定向或超大响应；更新手动/自动关闭/自动开启。

**通过条件：** 未授权不发请求；展示直接接收方与数据范围；搜索与模型凭据隔离；抓取目标和重定向符合策略；不能因页面或模型输出 URL 就任意抓取；默认无自动更新流量。

## 6. 退出条件

### 允许开始核心功能实施

- D-01–D-06 已形成唯一、可实现的规格。
- V-01–V-07、V-09、V-11 中影响主架构的路径有实证或明确接受的产品降级。
- 抽取方案已通过 V-08 的代表性对比，不要求所有冷门站点完美。
- 渲染和最小 UI 满足 V-10、V-12，性能 V-13 有基线数据。
- 公司网络实测若尚未完成，应明确标成发布阻塞，而不是已经支持。

### 允许对外宣称首期能力完成

- 对应阶段的需求与验收全部映射到测试，未实现能力不进入宣传。
- 所有该阶段 P1 已关闭或由明确记录的产品决策缩小支持范围。
- V-14–V-16 按实际启用功能通过；未启用功能不被暗中请求或加载。
- 用户能从“打开新资料页→总结”和“选中疑问→问答”完成实际工作，并能理解答案来源、读取范围与失败原因。
