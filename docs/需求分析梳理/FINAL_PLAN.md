## 1. 任务定义与边界

做一个**兼容 Edge 与 Chrome 的浏览器扩展**：读网页时选中文字一步提问、拿到带上下文的回答；一键总结整页、自由对话；问答可沉淀、可导出。开源到 GitHub。

综合两个参考项目：SelectLingo 的选中即弹工具栏与精致 UI，Sidebar Copilot 的整页理解与对话能力。修正两者的问题：补思考模式；修复引用不更新；解决长文中段被静默砍掉；把小窗做成正式功能并能选模型；连上公司中转站。

**边界**
- 首期只处理普通网页。PDF、浏览器内部页面（`edge://`、扩展商店）不在首期范围。
- 不替用户操作网页（点击、填表、控制媒体）。这类任务交给专门的 Agent（Codex / Claude）。
- 不做翻译专项产品（用户已有翻译插件）。

## 2. 核心理念与目标

**核心理念：阅读助手，帮用户在阅读、学习、查阅资料时保持心流。轻量、快速是最高准则。**

理念落地为三条可检验的约束（其余指标留到原型阶段按手感校准，不提前写死数值）：

- **操作步数**：核心的「划词提问」与「总结本页」都不能超过两次操作即可开始。
- **不拖慢网页**：插件对宿主页面加载与滚动的影响必须有上限，具体阈值在原型阶段测定后补入第 9 节。
- **不打扰**：任何提示、升级、引导都不能以模态弹窗打断阅读；所有提示都用小字或角标。

**目标**
1. 划词即问：选中文字后一步到达提问，回答带合适的上下文。
2. 整页理解：一键总结、提取要点，随时自由对话。
3. 阅读沉淀：问过、存过的内容可回顾、可导出。
4. 模型自由：只配一个默认模型就能用；需要时随手切换模型和思考强度；公司网络与 VPN 下都能用公司中转站。

**主要阅读场景**：技术文档、中文网页、文献页面、英文网页、英文开源仓库（GitHub）。

## 3. 关键决策及理由

| 决策 | 理由 |
| --- | --- |
| 只有「小窗 + 侧边栏」两个界面，不做页内卡片 | 卡片太小，除了翻译不好用；两个概念最轻 |
| 小窗浮在网页上，而不是独立系统窗口 | 扩展打开的独立窗口不能置顶，点网页划词时会被盖住，打断「划词 → 问」 |
| 「问」= 打开小窗并等待输入；「解释」= 立即用默认提示词回答 | 两者职责不同，避免「点问之后回答什么」的歧义 |
| 工具栏最多 5 个按钮，其余收进「更多」 | 再多就找不到，也挤占选区 |
| 上下文默认全文优先，只在超大页面降档 | DeepSeek 当前上下文 1M，输入费用低到可以忽略，长文降档的理由只剩首字延迟 |
| 「带上下文」档额外附带标题链与关键实体回指 | 解决「1927/1934」这类指代在远处、前后若干段覆盖不到的问题 |
| 超长页面的总结只读模型上下文的 20%–40%（默认 30%，可调） | 避免把模型撑爆、首字延迟过长；小字提示读了多少 |
| 同一页面再次打开，默认显示上次总结 | 省一次等待和费用；要新的就点重新总结 |
| 引用跳转采用「原文片段 → 所在段落 → 页内位置」三级降级 | 页面重排后按坐标必崩，按文本锚定才稳 |
| 回答里的引用只认模型逐字摘录的原文片段 | 找不到就不显示为可点击，避免跳到错误位置 |
| 收藏时同时保存原文快照 | 原网页改了或打不开时，笔记里仍能看到当时的内容 |
| 回答默认先给简短结论，可点「展开讲讲」 | 输出越短越快，也越不打断阅读 |
| 问题建议并列显示在输入框下方，不轮播；本地规则先出，模型建议后补 | 轮播一次只能看一条，会动的文字也抢注意力；只有本地规则能保证赶在用户开始打字之前 |
| 原文没交代时，必须写明「原文没有说明，以下来自模型自身知识」 | 读者要能分辨答案来源 |
| 思考强度出厂关闭 | DeepSeek 当前模型默认开启思考，不显式关闭会让每次「解释」都变慢 |
| 对话只在近期内自动续接 | 避免一周后随手一问接到很长的旧对话，变慢、变贵、语境乱 |
| 小窗收起不打断生成 | 否则就是 SelectLingo「卡片太脆」的翻版 |
| 提示词全部可改，但出厂必须是一套能用的默认值 | 可改是自由，默认是责任 |
| 设置项分层：常用的露在外面，其余收进「高级选项」 | 保持简洁又不丢自定义能力 |
| 联网搜索默认关闭，开启后也要逐条点「联网」才搜 | 搜索慢、花钱，只在用户主动要求时发生 |
| 所有 AI 请求由扩展后台发出 | 从网页内部发请求会被浏览器拦截内网地址 |
| 中转站地址要能自动发现缺少 `/v1` | 实测少了 `/v1` 时中转站返回网页且状态码 200，旧插件误判为成功 |
| 安装后用一段示例文章带用户亲手操作一遍 | 一次学会核心操作，之后不再弹提示打断心流 |

## 4. 典型用户流程

0. **首次安装**：装好后自动打开欢迎页 → 按向导选服务商、填 Key、测试连接、选默认模型 → 在示例文章上试一遍「选中 → 问 → 切档位 → 点引用 → 存」→ 记下快捷键。
1. **划词快问**：选中一段 → 工具栏弹出 → 点「问」→ 小窗浮出，引用已带上，光标在输入框，下方列出几条建议问题 → 点一条直接发送，或自己输入后回车 → 回答先给简短结论 → 点「展开讲讲」看细节，或点下方的追问建议继续 → 点网页其他地方，小窗收起（回答继续生成）。
2. **划词直解**：选中一句晦涩的话 → 点「解释」→ 立即回答，不经过输入框。
3. **深入讨论**：在小窗点「转到侧边栏继续」→ 侧边栏接着同一段对话 → 之后再划词提问，直接在侧边栏回答。
4. **整页理解**：工具栏或右键点「总结本页」（或按快捷键）→ 小窗显示结论、要点和章节脉络，每条要点可点回原文 → 需要时打开「联网」补充资料。
5. **看图**：快捷键框选截图，或鼠标悬停在网页图片上点「引用这张图」，然后提问。
6. **沉淀回顾**：点「存」收藏 → 在侧边栏查看本页记录 → 导出 Markdown。再次打开同一页，看到上次的总结。

## 5. 需求清单

**分级说明**
- **首期重要**：第一个可用版本必须具备。
- **首期次要**：属于首期范围，在第一个版本之后紧接着补上。
- **后期**：明确要做，但不在首期。
- **不做**：明确排除。

### 5.1 首期重要

**A. 划词工具栏**
- A1 选中文字后立即弹出工具栏。在输入框和可编辑区域里不弹；只读输入框不在此列（GitHub 代码页的选区就落在只读输入框里，必须支持）。
- A2 默认三个按钮：「问」「解释」「存」。工具栏最多显示 5 个，多出的动作收进「更多」。
- A3 自定义动作：每个动作有名字、提示词和作用范围（选中内容 / 整页）。可以增删、排序。工具栏按钮、小窗和侧边栏里的快捷动作共用这一套。预置「总结本页」「提取要点」「这页在讲什么」。所有提示词都可以编辑，并提供「恢复默认」。
- A4 网站黑名单：在指定网站上不弹工具栏。另设「不读取页面内容」级别，适用于公司内网等不能外发内容的站点。
- A5 工具栏行为：出现在选区下方，下方空间不足时出现在上方，不遮挡选中的文字；滚动、点击空白、按 Esc、开始输入、复制后自动消失；选中少于 2 个字不弹；位置不需要拖动记忆。
- A6 选区落在代码块里时，第一个按钮切换为「解释代码」（使用代码语境提示词）。
- A7 选中内容过长（超过约 5000 字）时先确认一次，避免误操作产生大额费用。
- A8 右键菜单提供「问」「解释」「总结本页」三个入口，与工具栏共用动作。工具栏被黑名单挡掉时仍然可用。

**B. 小窗**
- B1 浮在网页上的面板：用快捷键呼出，可拖动、可缩放，不挤压网页。位置默认记住上次的位置和大小；设置里可改为「出现在选区附近」。
- B2 内容包括：引用条、对话区、输入区。输入区可以切换模型、思考强度和上下文档位。
- B3 关闭方式：默认点网页就自动收起；图钉按钮可临时钉住；设置里可改默认方式；按 Esc 或点 × 关闭。
- B4 收起不打断生成：回答在后台继续，再次呼出时立即恢复当前内容。
- B5 全局只有一个小窗，跟着划词走，沿用当前对话。默认「点网页自动关」时，新划词会先收起再在新位置弹出；钉住时新选中的文字直接更新引用。
- B6 有「转到侧边栏继续」，对话无缝接上。
- B7 侧边栏已经打开时，划词提问直接在侧边栏回答，不再弹小窗。
- B8 小窗上有一行小字显示本次实际送了什么：选中多少字、带了前后几段、回指命中几处、全文共多少字、是否截断。

**C. 侧边栏**
- C1 完整的对话体验：逐字输出、Markdown 渲染、代码一键复制、数学公式渲染、停止、重试。
- C2 跟随当前标签页：显示这一页的对话列表，默认接着近期的那一个，也可以新建。
- C3 显示当前页信息：标题、能读取的字数、有没有被截断、上次总结的时间。
- C4 整页类快捷动作（来自 A3）。
- C5 历史记录：按页面或网站分组，可搜索、可删除。
- C6 打开侧边栏导致页面重排时，保持正在读的段落仍在视野内。

**D. 上下文与页面读取**
- D1 三个档位：
  - 只看选中；
  - 带上下文：所在段落及前后各 3 段，加上页面标题、网址、所在章节的标题链，以及关键实体回指（D5）；
  - 带全文。
- D2 默认全文优先。只有页面超出当前模型上下文预算的很高的比例时才降为「带上下文」；门槛可以在设置里调，也可以设成固定档位。
- D3 在小窗和侧边栏里都能一键切换档位。
- D4 超出预算被截断时，要明确提示截断了哪一部分（例如「只发送了第 1–9 章，约 2.1 万字」），不能悄悄砍掉。划词提问截断时以选中位置为中心向外保留；总结不同（见 D9）。
- D5 关键实体回指：发送前从选中的文字里识别年份、数字、专有名词、书名号/引号内术语，在同一页正文中检索它们的其他出现位置（最多 5 处），把这些位置所在的段落及其章节标题一并带上，并在引用条上方用小字说明「命中 N 处提及」。若某个实体在全页只出现这一次，提示「『1927』在页面中只出现一次，答案可能在别处；可切换全文」。
- D6 页面读取：正文按语义结构识别，去掉导航、广告、评论区等噪音；代码块、表格、公式、标题层级整体保留，不做拆解清洗。
- D7 折叠但已在页面中的正文要读取（按计算样式判断可见性，不只按内联样式）。
- D8 单页应用换页（地址或主内容变化）后自动重新读取；GitHub 这类站点不需要用户手动刷新。
- D9 超长页面的总结只读取模型上下文的 20%–40%（默认 30%，设置里可调），从小字提示「本次读取全文的 30%，约 1.2 万字」。设置里可另开「分块总结」（首期次要 I7），对超长页面逐块摘要再合并。
- D10 子页面（iframe）中的正文与划词都要支持；无法读取的页面类型给出明确提示（浏览器内部页面、扩展商店、canvas 渲染的文字）。Shadow DOM 里的内容（评论区等 Web Component）列为已知边界。
- D11 小窗或侧边栏开着时，新选中的文字立即更新引用，可点 × 取消（修复 Sidebar Copilot 的引用不更新）。
- D12 在同一篇文章里连续划词提问，默认接到这一页当前的对话里（续接规则见 D13）。
- D13 续接规则：距上次在该页提问不超过 30 分钟，且当前对话不超过 20 轮，才自动续接；否则新建对话并提示「已开启新对话，旧的仍可在历史里找回」。
- D14 网页内容一律当作不可信数据处理。回答里的外链图片不自动加载；模型输出按不可信内容渲染，过滤脚本和危险标签；回答里的链接在新标签页打开。
- D15 页面读取失败时给明确原因和下一步建议，不能静默返回空结果。兜底顺序：先退回读取浏览器已渲染的 DOM，再退回提示用框选截图提问。
- D16 用不了的地方（浏览器内部页面等）给出明确提示。

**E. 图片**
- E1 框选截图（用快捷键或按钮），截图作为引用发给模型。划不了词的页面（canvas、图片型内容）也走这条路，提示里写明。
- E2 默认不附带页面里的图片；设置里有开关「把上下文中的图片一起发给模型」。
- E3 当前模型不支持看图时，提示切换到能看图的模型。
- E4 模型对图片的回答要附一句轻提示「图表解析可能不完全准确，建议核对原图」。

**F. 引用与跳回原文**
- F1 回答里被模型逐字摘录的原文片段可以点击，点击后页面滚动到对应位置并高亮。
- F2 定位采用三级降级：精确句子 → 所在段落 → 页内大致位置。降级时提示「原文可能已变化，这是最接近的位置」。完全找不到时不显示为可点击。
- F3 总结和提取要点的每一条都带可点击的位置锚点，能跳回对应章节或段落。
- F4 从引用跳走之后，提供一次「回到刚才阅读的位置」。

**G. 收藏与沉淀**
- G1 一键收藏选中的文字和 AI 的回答，记录来源页面，并同时保存原文片段本地快照（原网页改了或打不开时仍可查看）。
- G2 收藏可以搜索、编辑，并导出为 Markdown。
- G3 首期不点「存」时也要有反馈：工具栏按钮短暂变为「已存」，侧边栏计数加一。

**H. 模型、思考与连接**
- H1 首次只需配置一个默认模型就能用，配置向导见 L2。
- H2 可以同时配置多个连接，每个连接起一个名字。预设 DeepSeek、Qwen、OpenAI、Claude、Gemini，也可以自定义任意 OpenAI 兼容服务。能拉取模型列表。
- H3 首期支持 OpenAI Chat Completions 一种接口，外加中转站容错。Responses 接口（GPT 思考摘要）与 Anthropic 原生接口放首期次要。
- H4 输入区可以临时切换模型和思考强度，只影响当前对话，界面保持简洁。
- H5 模型下拉框只显示用户勾选的常用模型，并且可以搜索（公司中转站上有 126 个模型）。
- H6 思考强度分「关 / 低 / 中 / 高」，出厂默认「关」，设置里可开。模型只支持开关时只显示开关。映射到主要几家：
  - DeepSeek：显式发送思考开关与强度；
  - Qwen：显式发送 thinking 开关；
  - GPT：首期只显示「思考中」，不显示摘要；
  - 其他模型：默认按「关」处理；
  - 高级设置里留一个「额外请求参数」输入框（JSON），给愿意自己调的人用。
  思考进行中要有明确状态；思考过程默认折叠，可以展开。
- H7 兼容公司中转站：支持自定义请求头；支持自定义完整的接口地址；支持内网地址和非标准端口；可以关闭逐字输出；不发送模型不支持的参数，出错时自动去掉可疑参数重试一次；**地址容错**：返回的是网页而不是接口数据时（比如少了 `/v1`），明确提示并能一键修正；状态码 200 但内容不是接口数据时，不能当作成功。
- H8 小窗和侧边栏里都能用内网中转站：所有 AI 请求都由扩展后台发出，不从网页里发。
- H9 测试连接：用一条真实的最小对话来测。失败时要说清楚具体原因，并显示服务器的原始报错；能一键复制诊断信息，Key 会被自动隐去。原因至少覆盖：地址写错或缺少 `/v1`；证书或代理问题；CORS / 403；Key 不对；路径或格式不对；参数不被支持；逐字输出被拦截；连不上内网中转站（提示检查公司网络或 VPN）；生成过程中断。
- H10 API Key 只存在本机，不同步。
- H11 内置常见模型的默认判断（是否支持思考、是否支持看图、走哪种接口、参数怪癖），每个模型可以手动改。参数被拒绝时自动去掉重试。
- H12 默认模型连不上时，提示一键切换到其他已配置的模型。

**I. 提示词与回答风格**
- I1 所有预置动作和快捷提示词都可以在设置里编辑，提供「恢复默认」。
- I2 回答长度三档：「简短」（默认，先给几句话的结论）、「正常」、「详细」。三档由不同的提示词控制，设置里可改默认档。
- I3 简短回答的下方有「展开讲讲」按钮，点了之后在原对话里继续展开。
- I4 默认提示词必须包含：优先给结论；引用原文时逐字摘录；原文没有交代的，必须写「原文没有说明，以下来自模型自身知识」；数字、年份、专有名词如与原文不一致要指出。
- I5 回答语言：默认中文，设置里可选「跟随网页语言」。
- I6 预置「总结本页」的输出规格：一句话结论（不超过 40 字）→ 3–5 条要点（每条不超过两行，带跳回原文的锚点）→ 章节脉络（页面超过 3 个标题时才给）。「提取要点」只给要点列表，「这页在讲什么」只给结论加一段说明。

**J. 通用**
- J1 同时兼容 Edge 和 Chrome。
- J2 深色模式跟随系统。
- J3 界面先做中文，文案结构为后期加英文界面做好准备。
- J4 快捷键：浏览器最多给一个扩展预设 4 个，所以预设 3 个，留 1 个不预设：
  - `Alt+Shift+S` 打开或关闭小窗，当前选中了文字时自动带上引用；
  - 一个键打开或关闭侧边栏；
  - 一个键框选截图；
  - 第 4 个留给用户自己绑定常用动作（命令面板见首期次要）。
  侧边栏的开关需要最低浏览器版本支持关闭接口，版本写在 J8。
- J5 UI 以 SelectLingo 的精致风格为基准，插件界面和网页样式互不干扰。
- J6 保持轻量：不申请调试权限这类重权限；没有触发时不拖慢网页，具体影响上限在原型阶段测定。
- J7 开源到 GitHub。SelectLingo 是 MIT 许可，复用其代码或样式需保留许可声明；Sidebar Copilot 没有许可证，只能借鉴思路，不能拷代码和素材。
- J8 最低浏览器版本：Edge / Chrome 141 起（关闭侧边栏的接口从 141 起提供；感知侧边栏开关状态的事件从 142 起提供，缺这个版本时降级为不自动判断）。
- J9 每条回答下方可展开「用量」，显示输入、输出 token 数（中转站返回时才有）。
- J10 模型名称必须与实际请求参数一致，不能出现界面标一个名字、实际调用另一个模型的情况。

**K. 设置项组织**
- K1 设置页只露常用项：默认模型、上下文档位、回答长度、思考开关、联网总开关、网站黑名单。
- K2 其余选项收进「高级选项」，默认折叠，旁边一句「这里有更多自定义选项」。折叠不减少能力，只减少视觉负担。
- K3 凡是会影响速度、费用、干扰程度、隐私，或需要刷新页面才生效的选项，旁边直接显示一两句说明（不藏在问号图标里），写清「开启或调高后会怎样」以及「代价是什么」。
- K4 小窗和侧边栏输入区里的临时开关，鼠标悬停时显示同样的简短说明。
- K5 示例文案：

| 选项 | 示例说明 |
| --- | --- |
| 联网搜索 | 开启后输入区出现「联网」按钮。点亮时回答更准确、来源更丰富，但每条回答会多等几秒到十几秒，并产生搜索费用。 |
| 默认上下文档位 / 长文门槛 | 门槛调高，更多文章会整篇发给模型，回答更完整，但首次等待更久；调低则相反。 |
| 总结读取比例（20%–40%） | 读得越多越完整，但首字更慢；超长页面建议保持 30%。 |
| 把上下文中的图片发给模型 | 模型能看懂文中的图表和公式图片，但每次请求更慢、更贵，且需要支持图片的模型。 |
| 默认思考开关 | 开启后更适合复杂问题，但等待更久、费用更高；只是解释一句话时建议关闭。 |
| 小窗默认关闭方式 | 「点网页自动关」问完即收，干扰最少；「钉住」方便对照原文，但会一直占着屏幕一角。 |
| 小窗位置 | 「记住上次位置」稳定可预期；「出现在选区附近」更贴近阅读位置，但每次会跳动。 |
| 打开时自动总结 | 打开小窗或侧边栏就自动总结本页，省一次点击；但每次打开都会花费并等待。 |
| 强制页面文字可选 | 让禁止复制的网站也能选中文字；可能影响页面上的拖拽等操作，刷新页面后生效。 |
| 网站黑名单 | 「不弹工具栏」只是不打扰；「不读取页面内容」会让快捷键也无法把该页内容发给模型。 |
| 逐字输出 | 关闭后要等整段回答生成完才一次性显示；只在中转站拦截逐字输出时才需要关闭。 |
| 分块总结 | 把超长页面分段摘要再合并，能覆盖全文，但更慢、更贵。 |
| 提问前的问题建议 | 点「问」时先把引用和少量上下文发给模型，生成几条你可能想问的问题；每次多一个很小的请求。标了「不读取页面内容」的网站不会触发。 |
| 按功能单独配置模型 | 留空则沿用默认模型；可以给总结配更强的模型，给解释配更快的模型。 |

**L. 安装与上手**
- L1 首次安装后自动打开欢迎页；之后可从设置页随时重新打开。
- L2 配置向导，只配一个默认模型，其余选项全部用默认值：
  - 选服务商（DeepSeek、Qwen、OpenAI、Claude、Gemini，或「自定义 / OpenAI 兼容」，公司中转站选这一项）；
  - 填地址和 Key，附「获取 API Key」链接；
  - 测试连接，直接复用 H9 的诊断和 H7 的地址纠错（例如自动发现缺少 `/v1`）；
  - 从模型列表里选默认模型，完成；
  - 可以跳过，之后在设置页配置。跳过时在网页上划词会提示去配置。
- L3 快速上手：欢迎页里放一段示例文章，三步静态图示（选中 → 问 → 存），可随时跳过。不做逐步强制引导。
- L4 显示快捷键：列出当前实际生效的快捷键，并提示把扩展图标固定到工具栏；某个快捷键因与其他扩展冲突而没生效时，明确提示并给出修改入口。
- L5 安装前已经打开的网页：能做到直接生效就直接生效；做不到的页面提示刷新一次。

**M. 产品原则（不可妥协）**
- M1 没有后端，不收集、不上传任何数据；页面内容只发往用户配置的模型服务。
- M2 使用自带 Key 或中转站时，插件侧绝不设用量上限、绝不截留请求。
- M3 未经用户明确同意，不修改主页、新标签页、默认搜索引擎等浏览器设置。
- M4 任何提示、升级或推广都不能用模态弹窗，不能打断正在进行的划词或阅读。
- M5 被关闭或不读取的站点不留后台脚本，不做持续注入。
- M6 密码框等敏感输入里的内容不读取、不发送、不保存。
- M7 网页的脚本读不到小窗和侧边栏里的对话内容。
- M8 联网抓取的目标地址必须可见、可审查，不允许由页面内容自行决定抓取任意地址（防提示注入诱导的越权请求）。

### 5.2 首期次要

- I7 分块总结：超长页面逐块摘要再合并，每条要点仍可溯源（默认关闭）。
- E5 点击或框选公式、图表，直接问「这是什么」（截图路线的专用入口）。
- E6 鼠标悬停在网页图片上时，出现「引用这张图」按钮；只在小窗或侧边栏打开时出现，避免持续视觉打扰。
- J11 命令面板：第 4 个快捷键可绑定为「呼出动作命令面板」，输入关键词模糊匹配自定义动作。面板按频率和新近度排序，可手动置顶。
- H13 按功能单独配置：在高级设置里给不同功能分别指定模型和思考强度。
- H14 Responses 接口（用于 GPT 思考摘要）与 Anthropic 原生接口。
- H15 Gemini 原生接口（首期可先走 Gemini 的 OpenAI 兼容接口）。
- G4 原网页高亮：收藏过或提问过的文字在原网页上留下高亮，再次打开同一页面时仍然在，点高亮能看到当时的问答。上线前须先验证定位可靠性。
- G5 每页阅读记录：按页导出高亮、问答和总结，可编辑，导出 Markdown；不做内置富文本编辑器。
- G6 导出结构化：原文片段、笔记、来源链接、时间拆成独立字段。
- G7 提供「换个模型重新回答」，沿用原来的上下文（追问建议见 I9）。
- G8 原网页高亮的颜色可区分来源（提问 / 收藏）。
- I8 短回答可选「整段一次性显示」，用于「解释」这类预期很短的场景。
- I9 问题建议：小窗和侧边栏的输入框下方并列显示 2–3 条建议问题，点一下直接发送；第一条同时以浅色幽灵字显示在输入框里，按 Tab 填入后可以修改。不轮播。建议分三个来源：
  - 规则建议：小窗打开的同时由本地规则生成，不发请求、不花钱。复用 D5 识别出的年份、数字、专有名词拼成问题，例如「这里的 1927 和 1934 分别指什么？」；选中代码时给代码类问题，例如「这段代码做了什么？」。
  - 提问前的模型建议：用默认模型、关闭思考，读引用和少量上下文生成，到达后追加在规则建议下方。不要求另配小模型；想用更快的模型，可在按功能单独配置（H13）里指定。这一层是否保留，由原型阶段实测命中率后决定（第 7 节）；保留时默认开启，可在高级选项关闭。
  - 回答后的追问建议：每次回答结束后给出 2–3 条，替换输入框下方的列表。
  约束：
  - 建议异步到达，不抢焦点，不挪动已经显示的内容；用户开始输入后收起列表，清空输入框后恢复。
  - 建议必须点名引用里的具体内容，不出现「这段话是什么意思」这类与「解释」重复的问题。
  - 追问建议不能拖慢回答，也不能混进回答正文。
  - 标了「不读取页面内容」的网站上，提问前的模型建议不触发。
- J12 打开时自动总结开关，默认关闭。
- J13 强制页面文字可选，用于禁止复制的网站，默认关闭。
- K6 设置可以一键导出、导入（JSON）。
- N1 联网搜索：设置里有总开关，默认关闭；开启后输入区出现「联网」按钮，只对当前这条消息生效；首期接入 DeepSeek 的搜索和网页抓取接口；搜索可以走已配置的连接，也可以单独配置 Key；回答标注来源链接；可以读取搜索结果的网页全文。

### 5.3 后期

- **后期靠前**：展开后再读（自动点「展开全文」「加载更多」后再读取）。
- 自定义动作可以单独指定模型、思考强度和上下文档位，也可以只在指定网站生效。
- 常读站点适配：GitHub 仓库、技术文档站、文献页。
- 外部笔记同步：Obsidian、Notion、本地文件夹。
- 英文界面。
- 其他搜索服务，如 Tavily、Exa。
- 关闭某些对话的自动保存（临时对话）。
- 跨文献、跨页面的联合问答：以结构化对比表呈现，需要先确定从哪几篇里选。
- 多模型并列对比回答。
- 事实核查模式：给出多来源列表，不替用户下结论。
- 跨标签页问答：采用「@指定标签页」的精确提及。
- 页面变化监测：用户框选关心的区域，设置检查频率，只在有意义变化时提醒。
- 收藏与历史的数据结构现在就要为上述功能预留「可检索文本片段 + 来源定位元数据」字段。
- 可考虑：DeepSeek 桌面端同步。
- PDF（可能改由其他工具承担）。

### 5.4 不做

- 页内卡片；
- 翻译专项优化（术语表、缓存、整页双语对照）；
- 标签页管理、站内搜索；
- 点击、勾选、选下拉；拖拽、滑块；上传文件；模拟真实键盘鼠标；
- 填写表单或输入文字；控制视频或音频；
- 语音输入；
- 自定义背景色；
- 上架扩展商店（目前）。

## 6. 约束与风险

| 约束 / 风险 | 影响与应对 |
| --- | --- |
| 扩展打开的独立窗口不能置顶 | 小窗做成浮在网页上的面板（已定） |
| 从网页内部向内网地址发请求会被浏览器拦截 | 所有 AI 请求由扩展后台发出（H8） |
| 浏览器内部页面、扩展商店禁止扩展注入 | 在这些页面明确提示不可用（D16） |
| 浏览器最多给一个扩展预设 4 个快捷键 | 预设 3 个，留 1 个给用户（J4） |
| 侧边栏的关闭与状态事件需要较新的浏览器版本 | 最低版本定为 141（J8），低版本降级 |
| 公司中转站只在公司网络或 VPN 下才能访问 | 连不上时提示检查 VPN，并提示切换模型（H9、H12） |
| 在真实浏览器扩展里访问内网中转站还没实测 | 下一阶段的原型首先验证这一点 |
| 依赖「加载解压缩」安装，不上架商店 | 扩展一被移除本机数据就会全清；手动更新容易被用户忽略。首期靠导出减损，更新提示列入待定 |
| 高亮定位在内容会变的页面上不稳 | 首期线下，G4 上线前先验证；收藏另存原文快照（G1） |
| 网页里的文字可能操纵模型 | 当作不可信数据（D14）；联网抓取目标必须可见（M8），但这只能降低风险 |
| 怎样算「同一页面」影响高亮和归档 | 默认忽略 `#锚点`；单页应用以主内容变化为准（D8），原型阶段细化 |
| 首期范围仍是同类产品里偏大的 | 已按第 8 节的核心闭环收窄，先做「划词 → 问 → 答 → 存 → 导出」 |
| 提问前的模型建议会在用户开口之前就发出引用和少量上下文 | 只发引用和少量上下文；标了「不读取页面内容」的网站不触发；可在高级选项关闭（I9） |
| 带全文、思考、联网都会增加花费和等待 | 默认值偏省：全文优先但超长页降档，思考默认关，联网和自动总结默认关 |
| SelectLingo 为 MIT，Sidebar Copilot 无许可证 | 复用前者需保留声明，后者只能借鉴思路 |

## 7. 推进路径

1. **需求定稿**（本文件）。
2. **下一次对话：架构设计与技术选型**，以本文件为输入。
3. **原型验证关键风险**，按顺序：
   1. 在 Edge 和 Chrome 中，扩展后台通过公司 WiFi 和 UniVPN 访问内网中转站；
   2. 浮在网页上的小窗与网页样式互不干扰，拖动和收起顺畅；
   3. 「带上下文」档位能抽到所在段落、前后各 3 段、标题链与实体回指；
   4. 引用跳回原文的三级降级能定位到正确位置；
   5. GitHub 代码页的只读输入框里划词能弹工具栏；
   6. 插件对宿主页面加载的影响、以及关键操作的实际耗时，用于补第 9 节的数值；
   7. 问题建议：提问前的模型建议能否赶在用户开始打字之前出现，以及用约 20 段真实阅读材料实测的命中率（三条建议里有几次正是想问的）。
4. **开发核心闭环**（见第 8 节），按第 9 节验收。
5. **开发其余首期次要**，然后进入后期。

「首期重要」仍是完整产品，但不要求一次做完。先交付下面这个核心闭环，其余紧随其后。

## 9. 验收标准（首期重要，从简）

1. 在普通网页选中文字，工具栏立即出现；点「问」后小窗出现、引用已带上、光标在输入框；输入问题后开始逐字回答。
2. 同一页面换选另一段，引用立即变成新内容。
3. 在长文中部选中一段，「带上下文」档位的回答能体现这一段前后的内容；若某实体在全页只出现一次，能看到对应的提示。
4. 划词提问和总结本页都不超过两次操作即开始回答。
5. 「解释」点下即答，不需要输入。
6. 小窗收起后回答继续，再次呼出能看到完整内容。
7. 使用思考模型时，思考中有状态提示；DeepSeek、Qwen 能展开看到思考内容。
8. 总结本页输出结论、要点和可点击的章节锚点；再次打开同一页默认显示上次总结；超长页有小字说明读取比例。
9. 在公司 WiFi 和 UniVPN 下，小窗和侧边栏都能通过公司中转站正常对话。
10. 中转站地址填成不带 `/v1` 的形式时，能明确提示并一键修正；测试连接失败时，能看到具体原因和服务器的原始报错。
11. 回答里的引用点击后，页面定位到原文并高亮；定位降级时能看到提示。
12. 只配置一个默认模型，就能完成以上全部操作。
13. 收藏内容可以搜索，并能导出为 Markdown。
14. 在 Edge 和 Chrome 里都能加载，并能完整使用。
15. 首次安装后自动打开欢迎页；只按向导填一个服务商和 Key，就能完成配置。
16. 扩展没有明显拖慢页面加载与滚动：具体数值在原型阶段测定后补入本条。
17. 页面内容确实没有交代时，回答里有「原文没有说明，以下来自模型自身知识」的标注。
18. 密码框中的内容不会进入任何请求。
