## 1. 任务定义与边界

做一个**兼容 Edge 与 Chrome 的浏览器扩展**：在读网页时，选中文字就能一步提问、拿到带上下文的回答；也能一键总结整页、自由对话，并把问答沉淀下来。开源到 GitHub。

它综合两个参考项目：
- **SelectLingo**：选中即弹出工具栏的交互，以及精致统一的 UI。
- **Sidebar Copilot**：整页理解、总结与对话能力。

同时修正两者的问题：
- 补上思考模式；
- 修复换选文字后引用不更新；
- 解决长文中段被悄悄砍掉；
- 把小窗做成正式功能，并能在其中选模型；
- 能连上公司中转站。

**边界**
- 首期只处理普通网页。PDF、浏览器内部页面（如 `edge://`、扩展商店）不在首期范围。
- 不替用户操作网页（点击、填表等）。这类复杂任务交给专门的 Agent（Codex / Claude）。
- 不做翻译专项产品（用户已有翻译插件）。

## 2. 目标与非目标

**核心理念：阅读助手，帮用户在阅读、学习、查阅资料时保持心流。轻量、快速是最高准则。**

**目标**
1. 划词即问：选中文字后一步到达提问，回答带合适的上下文。
2. 整页理解：一键总结、提取要点，随时自由对话。
3. 阅读沉淀：问过、存过的内容可回顾、可导出。
4. 模型自由：只配一个默认模型就能用；需要时随手切换模型和思考强度；在公司网络和 VPN 下都能用公司中转站。

**非目标**：见第 5.4 节「不做」。

**主要阅读场景**：技术文档、中文网页、文献页面、英文网页、英文开源仓库（GitHub）。

## 3. 关键决策及理由

| 决策 | 理由 |
| --- | --- |
| 只有「小窗 + 侧边栏」两个界面，不做页内卡片 | 卡片太小，除了翻译不好用；两个概念最轻 |
| 小窗浮在网页上，而不是独立系统窗口 | 扩展打开的独立窗口不能置顶，点网页划词时会被浏览器盖住，打断「划词 → 问」 |
| 小窗默认点网页就自动收起，带图钉按钮 | 问完即收，减少干扰；需要对照原文时点图钉钉住 |
| 选中文字即弹出工具栏，工具栏可以拖动 | 操作路径最短；拖开后不挡内容 |
| 工具栏按钮与快捷动作共用一套自定义动作 | 只需在一处维护 |
| 上下文分三档，默认按文章长短自动判断，截断必须提示 | 避免只看选中、断章取义，也避免像 Copilot 那样悄悄砍掉中间 |
| 对话按页面归档，连续划词接入当前对话 | 读同一篇文章时前后连贯，回到原页能找回之前的对话 |
| 只需配一个默认模型，按功能单独配置放在高级设置 | 首次配置不烦人 |
| 联网搜索默认关闭，开启后也要逐条点「联网」才搜 | 搜索慢、花钱，只在用户主动要求时发生 |
| 页面操作（Agent）全部推到后期或不做 | 偏离阅读场景，又重又有风险 |
| 中转站地址要能自动发现缺少 `/v1` | 实测发现：少了 `/v1` 时中转站返回网页首页且状态码是 200，旧插件会误判为成功，这是之前连不上的最可能原因 |
| 会影响体验的设置项，旁边直接写明收益和代价 | 打开开关之前就知道会变快还是变慢、多花多少，不用试错 |
| 安装后用一段示例文章带用户亲手操作一遍 | 一次学会核心操作，之后真实阅读时不再弹提示打断心流 |

## 4. 典型用户流程

0. **首次安装**：装好后自动打开欢迎页 → 按向导选服务商、填 Key、测试连接、选默认模型 → 在示例文章上亲手试一遍「选中 → 问 → 转侧边栏 → 存」→ 记下快捷键，开始阅读。
1. **划词快问**：选中一段 → 工具栏弹出 → 点「问」→ 小窗浮出，带着引用开始回答 → 可以追问、切换上下文档位、点引用跳回原文 → 点网页其他地方，小窗收起。
2. **深入讨论**：在小窗点「转到侧边栏继续」→ 侧边栏接着同一段对话 → 之后再划词提问，直接在侧边栏回答。
3. **整页理解**：快捷键呼出小窗或打开侧边栏 → 点「总结本页」或「提取要点」→ 需要时打开「联网」补充资料。
4. **看图**：快捷键框选截图，或者鼠标悬停在网页图片上点「引用这张图」，然后提问。
5. **沉淀回顾**：点「存」收藏 → 下次打开同一页面，能看到高亮和之前的对话 → 在侧边栏查看本页的阅读笔记 → 导出 Markdown。

## 5. 需求清单

**分级说明**
- **首期重要**：第一个可用版本必须具备。
- **首期次要**：属于首期范围，在第一个版本之后紧接着补上。
- **后期**：明确要做，但不在首期。
- **不做**：明确排除。

### 5.1 首期重要

**A. 划词工具栏**
- A1 选中文字后立即弹出工具栏。在输入框和可编辑区域里不弹。工具栏可以拖动。
- A2 默认三个按钮：「问」「解释」「存」。
- A3 自定义动作：每个动作有名字、提示词和作用范围（选中内容 / 整页）。可以增删、排序。工具栏按钮和小窗、侧边栏里的快捷动作共用这一套。预置「总结本页」「提取要点」「这页在讲什么」。
- A4 网站黑名单：在指定网站上不弹工具栏。

**B. 小窗**
- B1 浮在网页上的面板：用快捷键呼出，可拖动、可缩放，不挤压网页；记住上次的位置和大小。
- B2 内容包括：引用条、对话区、输入区。输入区可以切换模型、思考强度和上下文档位。
- B3 关闭方式：默认点网页就自动收起；图钉按钮可临时钉住；设置里可改默认方式；按 Esc 或点 × 关闭。
- B4 全局只有一个小窗，跟着划词走，沿用当前对话。
- B5 有「转到侧边栏继续」，对话无缝接上。
- B6 侧边栏已经打开时，划词提问直接在侧边栏回答，不再弹小窗。

**C. 侧边栏**
- C1 完整的对话体验：逐字输出、Markdown 渲染、代码一键复制、停止、重试。
- C2 跟随当前标签页：显示这一页的对话列表，默认接着最近一个，也可以新建。
- C3 显示当前页信息：标题、能读取的字数、有没有被截断。
- C4 整页类快捷动作（来自 A3）。
- C5 历史记录：按页面或网站分组，可搜索、可删除。

**D. 上下文**
- D1 三个档位：
  - 只看选中；
  - 带上下文：所在段落及前后若干段，加上页面标题和网址；
  - 带全文。
- D2 默认按文章长短自动选档：短文给全文，长文给上下文。判断长短的门槛可以在设置里调，也可以设成固定档位。
- D3 在小窗和侧边栏里都能一键切换档位。
- D4 全文太长被截断时，要明确提示截断了、截掉的是哪一部分，不能悄悄砍掉。
- D5 小窗或侧边栏开着时，新选中的文字立即更新引用，可点 × 取消（修复 Sidebar Copilot 的引用不更新）。
- D6 在同一篇文章里连续划词提问，默认接到这一页当前的对话里。
- D7 网页内容一律当作不可信数据处理，降低网页里的文字操纵模型的风险。
- D8 在浏览器内部页面等用不了的地方，给出明确提示。

**E. 图片**
- E1 框选截图（用快捷键或按钮），截图作为引用发给模型。
- E2 默认不附带页面里的图片；设置里有开关「把上下文中的图片一起发给模型」。
- E3 当前模型不支持看图时，提示切换到能看图的模型。

**F. 引用跳回原文**
- F1 回答里引用的原文可以点击，点击后页面滚动到对应位置并高亮。

**G. 收藏**
- G1 一键收藏选中的文字和 AI 的回答，并记录来源页面。
- G2 收藏和历史都可以搜索、编辑，并导出为 Markdown。

**H. 模型、思考与连接**
- H1 首次只需配置一个默认模型就能用，配置向导见 L2。
- H2 可以同时配置多个连接，每个连接起一个名字。预设 DeepSeek、Qwen、OpenAI、Claude、Gemini，也可以自定义任意 OpenAI 兼容服务。能拉取模型列表。
- H3 支持三种接口：OpenAI Chat Completions、OpenAI Responses、Anthropic（Claude）原生接口。同一个连接下，不同模型可以用不同接口；例如 GPT 走 Responses，才能显示思考摘要。
- H4 输入区可以临时切换模型和思考强度，只影响当前对话，界面保持简洁。
- H5 模型下拉框只显示用户勾选的常用模型，并且可以搜索（公司中转站上有 126 个模型）。
- H6 思考强度分「关 / 低 / 中 / 高」，模型只支持开或关时只显示开关。思考进行中要有明确状态。思考过程默认折叠，可以展开：
  - DeepSeek、Qwen：显示思考内容；
  - GPT：显示思考摘要；
  - 拿不到思考内容的模型：只显示"思考中"。
- H7 兼容公司中转站：
  - 支持自定义请求头；
  - 支持自定义完整的接口地址；
  - 支持内网地址和非标准端口；
  - 可以关闭逐字输出；
  - 不发送模型不支持的参数；
  - **地址容错**：返回的是网页而不是接口数据时（比如少了 `/v1`），明确提示并能一键修正；状态码是 200 但内容不是接口数据时，不能当作成功。
- H8 小窗和侧边栏里都能用内网中转站：所有 AI 请求都由扩展后台发出，不从网页里发。
- H9 测试连接：用一条真实的最小对话来测。失败时要说清楚具体原因，并显示服务器的原始报错；能一键复制诊断信息，Key 会被自动隐去。可能的原因包括：
  - 地址写错或缺少 `/v1`；
  - 证书或代理问题；
  - Key 不对；
  - 路径或格式不对；
  - 参数不被支持；
  - 逐字输出被拦截；
  - 连不上内网中转站（会提示检查公司网络或 VPN）。
- H10 API Key 只存在本机，不同步。

**J. 通用**
- J1 同时兼容 Edge 和 Chrome。
- J2 深色模式跟随系统。
- J3 界面先做中文，文案结构要为后期加英文界面做好准备。
- J4 快捷键：
  - `Alt+Shift+S` 打开或关闭小窗，当前选中了文字时自动带上引用；
  - 一个键打开或关闭侧边栏；
  - 一个键框选截图；
  - 预留一个键，供用户绑定常用的自定义动作。
- J5 UI 以 SelectLingo 的精致风格为基准，插件界面和网页样式互不干扰。
- J6 保持轻量：不申请调试权限这类重权限，不明显拖慢网页。
- J7 开源到 GitHub。

**K. 设置项说明**
- K1 凡是会影响速度、费用、干扰程度、隐私，或需要刷新页面才生效的选项，旁边直接显示一两句说明（不藏在问号图标里），写清「开启或调高后会怎样」以及「代价是什么」。
- K2 需要说明的选项与示例文案见下表，最终文案可在开发时调整。
- K3 小窗和侧边栏输入区里的临时开关（思考强度、联网、上下文档位），鼠标悬停时显示同样的简短说明。

| 选项 | 示例说明 |
| --- | --- |
| 联网搜索（I1） | 开启后输入区出现「联网」按钮。点亮时回答更准确、来源更丰富，但每条回答会多等几秒到十几秒，并产生搜索费用。 |
| 默认上下文档位 / 长短文门槛（D2） | 门槛调高，更多文章会整篇发给模型，回答更完整，但更慢、更费钱；调低则相反。 |
| 把上下文中的图片发给模型（E2） | 模型能看懂文中的图表和公式图片，但每次请求更慢、更贵，且需要支持图片的模型。 |
| 默认思考强度（H6、H11） | 越高越适合复杂问题，但等待更久、费用更高；只是解释一句话时建议关闭或选低。 |
| 小窗默认关闭方式（B3） | 「点网页自动关」问完即收，干扰最少；「钉住」方便对照原文，但会一直占着屏幕一角。 |
| 打开时自动总结（J8） | 打开小窗或侧边栏就自动总结本页，省一次点击；但每次打开都会花费并等待，哪怕你只是想问别的。 |
| 强制页面文字可选（J9） | 让禁止复制的网站也能选中文字；可能影响页面上的拖拽等操作，刷新页面后生效。 |
| 网站黑名单（A4） | 在这些网站上不弹工具栏，仍可用快捷键呼出小窗。 |
| 逐字输出（H7） | 关闭后要等整段回答生成完才一次性显示；只在中转站拦截逐字输出时才需要关闭。 |
| 自定义请求头（H7） | 一般不用填；只在中转站要求额外的请求头时使用。 |
| 按功能单独配置模型（H11） | 留空则沿用默认模型；可以给总结配更强的模型，给解释配更快的模型。 |

**L. 安装指引**
- L1 首次安装后自动打开欢迎页；之后可从设置页随时重新打开。
- L2 配置向导，只配一个默认模型，其余选项全部用默认值：
  - 选服务商（DeepSeek、Qwen、OpenAI、Claude、Gemini，或「自定义 / OpenAI 兼容」，公司中转站选这一项）；
  - 填地址和 Key，附「获取 API Key」链接；
  - 测试连接，直接复用 H9 的诊断和 H7 的地址纠错（例如自动发现缺少 `/v1`）；
  - 从模型列表里选默认模型，完成；
  - 可以跳过，之后在设置页配置。
- L3 快速上手：欢迎页里放一段示例文章，引导用户亲手做一遍「选中文字 → 点『问』→ 切换上下文档位 → 点引用跳回原文 → 转到侧边栏 → 点『存』」。每一步做完自动进入下一步，可以随时跳过。
- L4 显示快捷键：列出当前实际生效的快捷键，并提示把扩展图标固定到工具栏；某个快捷键因与其他扩展冲突而没生效时，明确提示并给出修改入口。
- L5 安装前已经打开的网页：划词工具栏要么能直接用，要么提示刷新该页面，避免用户以为插件坏了。

### 5.2 首期次要

- G3 原网页高亮：收藏过或提问过的文字在原网页上留下高亮，再次打开同一页面时仍然在；点高亮能看到当时的问答。
- G4 每页阅读笔记：自动汇总这一页的高亮、问答和总结，可以编辑，可以导出 Markdown。
- E4 鼠标悬停在网页图片上时，出现「引用这张图」按钮。
- I1 联网搜索：
  - 设置里有总开关，默认关闭；
  - 开启后输入区出现「联网」按钮，只对当前这条消息生效；
  - 首期接入 DeepSeek 的搜索和网页抓取接口；
  - 搜索可以走已配置的连接（实测公司中转站支持），也可以单独配置 Key；
  - 回答标注来源链接；
  - 可以读取搜索结果的网页全文。
- H11 按功能单独配置：在高级设置里给不同功能分别指定模型和思考强度。
- H12 默认模型连不上时，提示一键切换到其他已配置的模型。
- H13 支持 Gemini 原生接口；首期可以先走 Gemini 的 OpenAI 兼容接口。
- J8 设置里提供「打开时自动总结」开关，默认关闭。
- J9 强制页面文字可选，用于禁止复制的网站，默认关闭。

### 5.3 后期

- **后期靠前**：展开后再读，也就是自动点「展开全文」「加载更多」后再读取。
- 自定义动作可以单独指定模型、思考强度和上下文档位。
- 常读站点适配：GitHub 仓库、技术文档站、文献页。
- 外部笔记同步：Obsidian、Notion、本地文件夹。
- 英文界面。
- 其他搜索服务，如 Tavily、Exa。
- 关闭某些对话的自动保存。
- 可考虑：DeepSeek 桌面端同步。
- PDF（可能改由其他工具承担）。
- **大后期**：跨标签页读取、打开链接并读取、填写表单或输入文字、控制视频或音频（危险操作需要确认）。

### 5.4 不做

- 页内卡片；
- 翻译专项优化（术语表、缓存、整页双语对照）；
- 标签页管理、站内搜索；
- 点击、勾选、选下拉；拖拽、滑块；上传文件；模拟真实键盘鼠标；
- 语音输入；
- 自定义背景色；
- 上架扩展商店（目前不考虑）。

## 6. 约束与风险

| 约束 / 风险 | 影响与应对 |
| --- | --- |
| 扩展打开的独立窗口不能置顶 | 小窗做成浮在网页上的面板（已定） |
| 从网页内部向内网地址发请求会被浏览器拦截 | 所有 AI 请求由扩展后台发出（H8） |
| 浏览器内部页面、扩展商店禁止扩展注入 | 在这些页面明确提示不可用（D8） |
| 浏览器最多给一个扩展预设 4 个快捷键 | 按 J4 分配，其余由用户自行绑定 |
| 公司中转站只在公司网络或 VPN 下才能访问 | 连不上时提示检查 VPN，并提示切换模型（H9、H12） |
| 在真实浏览器扩展里访问内网中转站还没实测（命令行已通） | 下一阶段的原型首先验证这一点 |
| 首期范围偏大 | 已拆成首期重要和首期次要，先做出"划词 → 问 → 收藏 → 导出"的闭环 |
| 带全文、思考、联网都会增加花费和等待 | 默认值偏省：按长短自动选档，联网和自动总结默认关闭 |
| 网页里的文字可能操纵模型 | 网页内容当作不可信数据（D7）；但这只能降低风险，不能杜绝 |
| 怎样算"同一页面"影响高亮和笔记归档 | 默认忽略 `#锚点`，其余按常理处理；原型阶段再细化 |

## 8. 验收标准（首期重要）

1. 在普通网页选中文字，工具栏立即出现；点「问」后小窗出现，并开始逐字回答。
2. 在同一页面换选另一段，引用立即变成新内容。
3. 在长文中部选中一段，"带上下文"档位的回答能体现这一段前后的内容；"带全文"被截断时，界面有明确提示。
4. 使用思考模型时，思考中有状态提示；DeepSeek、Qwen 能展开看到思考内容，GPT 能看到思考摘要。
5. 在公司 WiFi 和 UniVPN 下，小窗和侧边栏都能通过公司中转站正常对话。
6. 中转站地址填成不带 `/v1` 的形式时，能明确提示并一键修正；测试连接失败时，能看到具体原因和服务器的原始报错。
7. 回答里的引用点击后，页面定位到原文并高亮。
8. 只配置一个默认模型，就能完成以上全部操作。
9. 收藏内容可以搜索，并能导出为 Markdown。
10. 在 Edge 和 Chrome 里都能加载，并能完整使用。
11. 首次安装后自动打开欢迎页；只按向导填一个服务商和 Key，就能完成配置，并在示例文章上完成一次划词提问。
12. 设置页里会影响速度、费用、干扰程度或需要刷新才生效的选项，旁边都有说明。
