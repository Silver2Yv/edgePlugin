# 需求文档草案 v0.5

> 状态：草案，待用户审阅。依据 `DECISIONS.md` 001–033。本文只含需求，不含架构、技术栈与实现细节。
> 产品名称：待定（暂称「本插件」）。

## 1. 背景与问题

用户试用了两个开源扩展，各有不足：

- **SelectLingo（划词译问）**：选中文字即弹出工具栏，操作最快、UI 精致；但提问时只给模型选中的几句话，没有上下文；不能总结整页、不能自由对话；思考内容被丢弃；不渲染 Markdown。
- **Sidebar Copilot**：能读整页、能总结、对话体验完整；但划词提问要走右键菜单；完全不支持思考模式；同页换选另一段后引用不更新；长文中段被静默砍掉；`Alt+Shift+S` 小窗其实是 bug 的副产物，面板里也不能选模型；Agent 能力很重，偏离阅读场景。
- 两者都连不上用户公司的中转站，且都不支持 PDF。

详见 `PROJECT_ANALYSIS.md`。

## 2. 核心理念与目标

**核心理念：阅读助手，帮用户在阅读、学习、查阅资料时保持心流。轻量、快速是最高准则。** 任何功能若打断心流或让插件变重，默认不做或放到后期。

目标：

1. 划词即问：选中文字后一步到达提问，回答带合适的上下文。
2. 整页理解：一键总结、提取要点，随时自由对话。
3. 阅读沉淀：问过、存过的内容可回顾、可导出。
4. 模型自由：只配一个默认模型即可用，需要时随手切换模型与思考强度；能连公司中转站。

## 3. 适用与不适用场景

**适用**：技术文档、中文网页、文献页面、英文网页、英文开源仓库（GitHub）。

**不适用（首期）**：PDF（用户可能改用其他工具）；浏览器内部页面（如 `edge://`、扩展商店）；需要替用户操作网页的任务（交给专门的 Agent，如 Codex / Claude）。

## 4. 典型用户流程

1. **划词快问**：选中一段 → 工具栏弹出 → 点「问」→ 小窗浮出、带着引用开始回答 → 追问 / 切换上下文档位 / 点引用跳回原文 → 点网页其他地方，小窗收起。
2. **深入讨论**：在小窗点「转到侧边栏继续」→ 侧边栏接着同一会话 → 之后再划词提问，直接在侧边栏回答。
3. **整页理解**：快捷键呼出小窗或打开侧边栏 → 点「总结本页」/「提取要点」→ 必要时打开「联网」补充资料。
4. **看图**：快捷键框选截图，或悬停在网页图片上点「引用这张图」→ 提问。
5. **沉淀回顾**：点「存」收藏 → 下次打开同一页面，看到高亮与之前的会话 → 在侧边栏查看本页阅读笔记 → 导出 Markdown。

## 5. 需求清单

分级说明：
- **首期重要**：第一个可用版本必须具备。
- **首期次要**：属于首期范围，可在第一个版本之后紧接着补上。
- **后期 / 大后期**：明确要做，但不在首期。
- **不做**：明确排除。

### 5.1 首期重要

**A. 划词工具栏**
- A1 选中文字后立即弹出工具栏；输入框和可编辑区域内不弹；工具栏可拖动。
- A2 默认按钮：「问」「解释」「存」。
- A3 自定义动作：名字 + 提示词 + 作用范围（选中内容 / 整页）；可增删、排序；工具栏与小窗/侧边栏的快捷动作共用这一套。预置「总结本页」「提取要点」「这页在讲什么」。
- A4 网站黑名单：在指定网站上不弹工具栏。

**B. 小窗**
- B1 浮在网页上的面板：快捷键呼出，可拖动、可缩放，不挤压网页；记住位置与大小。
- B2 包含引用条、对话区、输入区；输入区可切换模型、思考强度、上下文档位。
- B3 关闭方式：默认点网页自动关；图钉按钮可临时钉住；设置里可改默认；Esc 或 × 关闭。
- B4 全局只有一个小窗，跟着划词走，沿用当前会话。
- B5 「转到侧边栏继续」，对话无缝接续。
- B6 侧边栏已打开时，划词提问直接在侧边栏回答，不弹小窗。

**C. 侧边栏**
- C1 完整对话：流式输出、Markdown 渲染、代码一键复制、停止、重试。
- C2 跟随当前标签页：显示该页会话列表，默认续接最近一个，可新建。
- C3 显示当前页信息：标题、可读取字数、是否截断。
- C4 整页类快捷动作（来自 A3）。
- C5 历史：按页面 / 网站分组，可搜索、删除。

**D. 上下文**
- D1 三个档位：只看选中 / 带上下文（所在段落及前后若干段 + 页面标题与网址）/ 带全文。
- D2 默认按长短文自动判断（短文给全文、长文给上下文），判断门槛可在设置里调；也可设为固定档位。
- D3 小窗与侧边栏中一键切换档位。
- D4 全文超长被截断时，明确提示截断了、截掉的是哪一部分，不能静默砍掉。
- D5 小窗或侧边栏打开时，新选中的文字立即更新引用，可 × 取消（修复 Sidebar Copilot 的引用不更新）。
- D6 同一篇文章内连续划词提问，默认接入该页当前会话。
- D7 页面内容作为不可信数据处理，降低网页文字操纵模型的风险。
- D8 浏览器内部页面等无法使用的地方，给出明确提示。

**E. 图片**
- E1 框选截图（快捷键或按钮），作为引用发给模型。
- E2 默认不附带页面图片；设置开关「把上下文中的图片一起发给模型」。
- E3 当前模型不支持图片时，提示切换到可看图的模型。

**F. 引用跳回原文**
- F1 回答中引用的原文可点击，页面滚动到对应位置并高亮。

**G. 收藏**
- G1 一键收藏选中文字与 AI 回答，记录来源页面。
- G2 收藏与历史可搜索、编辑、导出 Markdown。

**H. 模型、思考与连接**
- H1 首次只需配置一个默认模型即可使用，有安装引导。
- H2 可同时配置多个命名连接；预设 DeepSeek、Qwen、OpenAI、Claude、Gemini，另可自定义任意 OpenAI 兼容服务；可拉取模型列表。
- H3 支持的接口格式：OpenAI Chat Completions、OpenAI Responses、Anthropic（Claude）原生格式。
- H4 输入区可临时切换模型与思考强度，只影响当前会话；界面保持简洁。
- H5 思考强度：关 / 低 / 中 / 高（模型只支持开关时只显示开关）；思考进行中有明确状态；思考过程默认折叠，可展开。
- H6 公司中转站兼容：自定义请求头、自定义完整接口地址、内网地址与非标准端口、可关闭流式输出、不发送模型不支持的参数（如推理模型的 temperature）。
- H7 在小窗与侧边栏中都能使用内网中转站（所有 AI 请求由扩展后台发出）。
- H8 测试连接：用真实的最小对话请求测试，失败时说明具体原因（地址、证书、代理、Key、路径、格式、参数、流式被拦等）并显示服务器原始报错，可一键复制诊断信息（自动隐去 Key）。
- H9 API Key 只存本机，不同步。

**J. 通用**
- J1 同时兼容 Edge 与 Chrome。
- J2 深色模式跟随系统。
- J3 界面中文；文案结构为后期英文界面做好准备。
- J4 快捷键：`Alt+Shift+S` 打开/关闭小窗（有选中文字时自动带引用）、打开/关闭侧边栏、框选截图、预留一个绑定常用自定义动作。
- J5 UI 以 SelectLingo 的精致风格为基准，界面元素与网页样式隔离。
- J6 轻量：不申请调试等重权限；不明显拖慢网页。
- J7 开源到 GitHub。

### 5.2 首期次要

- G3 原网页高亮：收藏或提问过的文字在原网页上留下高亮，再次打开同一页面仍在；点高亮可看当时的问答。
- G4 每页阅读笔记：自动汇总本页的高亮、问答与总结，可编辑，可导出 Markdown。
- E4 鼠标悬停网页图片时出现「引用这张图」按钮。
- I1 联网搜索：设置总开关（默认关）；开启后输入区出现「联网」按钮，只对当前消息生效；首期接入 DeepSeek Search / Fetch；搜索 Key 单独配置，可复用 DeepSeek 的 Key；回答标注来源链接；可读取搜索结果网页全文。
- H10 按功能覆盖：在设置高级项里给不同功能单独指定模型与思考强度。
- H11 默认模型连不上时，提示一键切换到其他已配置模型。
- H12 Gemini 原生格式（首期可先走 Gemini 的 OpenAI 兼容接口）。
- J8 打开时自动总结开关（默认关）。
- J9 强制页面文字可选（用于禁止复制的网站，默认关）。

### 5.3 后期

- 后期靠前：展开后再读（自动点「展开全文 / 加载更多」后再读取）。
- 自定义动作单独指定模型、思考强度、上下文档位。
- 常读站点适配：GitHub 仓库、技术文档站、文献页。
- 外部笔记同步：Obsidian / Notion / 本地文件夹。
- 英文界面。
- 其他搜索服务：Tavily、Exa 等。
- 关闭某些会话的自动保存。
- 可考虑：DeepSeek 桌面端同步。
- PDF（可能改由其他工具承担）。
- 大后期：跨标签页读取、打开链接并读取、填写表单或输入文字、控制视频或音频（危险操作需确认）。

### 5.4 不做

页内卡片；翻译专项优化（术语表、缓存、整页双语）；标签页管理；站内搜索；点击 / 勾选 / 选下拉；拖拽 / 滑块；上传文件；模拟真实键鼠；语音输入；自定义背景色；上架扩展商店（目前）。

## 6. 验收标准（首期重要）

1. 在普通网页选中文字，工具栏立即出现；点「问」后小窗出现并开始流式回答。
2. 同一页面换选另一段，引用立即变为新内容。
3. 在长文中部选中一段，「带上下文」档位的回答能体现该段前后内容；「带全文」被截断时界面有明确提示。
4. 使用思考模型时，思考中有状态提示，思考过程可展开查看。
5. 在公司 WiFi 与 UniVPN 下，通过公司中转站，小窗与侧边栏都能正常对话。
6. 测试连接失败时，能看到具体原因和服务器原始报错。
7. 回答中的引用点击后，页面定位到原文并高亮。
8. 只配置一个默认模型即可完成以上全部操作。
9. 收藏内容可搜索并导出为 Markdown。
10. Edge 与 Chrome 都能加载并完整使用。

- 阅读笔记是否需要标签 / 分组；历史清理与成本控制（P2，可后定）。
