# 网络诊断包 · 安装与测试步骤

这是阅读助手的原型测试包，不是正式扩展。它只做一件事：在你的电脑和网络下，测浏览器扩展连公司中转站是否通畅、流式输出是否正常、长时间输出会不会被浏览器中断。

全程约 15 分钟（不含可选的第 5 步）。做完把**回填表**发回即可。

## 安全须知

| 事项 | 说明 |
| --- | --- |
| Key 存在哪 | 只在浏览器内存里，关闭浏览器即清除，不写入硬盘 |
| 导出结果 | 已自动把 Key 和服务器地址替换成 `<key>`、`<relay>` |
| 请不要 | 把 Key 发到聊天、邮件或回填表里。有疑问只描述现象 |
| 测完之后 | 在扩展管理页点「移除」即可彻底删除 |

## 1. 安装

| 步骤 | Chrome | Edge |
| --- | --- | --- |
| 解压 | 把压缩包解压到任意文件夹，里面有 `extension` 文件夹 | 同左 |
| 打开扩展管理页 | 地址栏输入 `chrome://extensions` | 地址栏输入 `edge://extensions` |
| 打开开发者模式 | 右上角「开发者模式」开关 | 左侧栏「开发人员模式」开关 |
| 加载 | 点「加载已解压的扩展程序」，选 `extension` 文件夹 | 点「加载解压缩的扩展」，选 `extension` 文件夹 |
| 固定图标 | 点工具栏拼图图标，把「阅读助手 · 网络诊断包」钉住 | 点工具栏扩展图标，设为「在工具栏中显示」 |

如果开发者模式开关是灰的、加载时报错或提示被管理员禁止，**这本身就是重要结果**：截图或记下原文，填进回填表第 1 节，然后停止。

## 2. 填写连接

点工具栏上的扩展图标，会打开诊断页。

1. 填接口地址（以 `/v1` 结尾）、Key、模型名（`deepseek-flash`）。
2. 点「保存连接」。
3. 在「本次测试环境」里选网络类型；确认开发者工具（F12）没开。

## 3. 快速测试（约 30 秒）

点「快速测试」，等状态变成「完成」。下方表格每行有「符合 / 不符合 / 记录」。

## 4. 长任务测试（每次约 2 分钟，做两次）

| 次序 | 操作 |
| --- | --- |
| 第一次 | 勾上「长任务期间保活」，点「长任务测试」，**立刻关掉诊断页**。等 3 分钟，再点扩展图标打开诊断页看结果 |
| 第二次 | 去掉「长任务期间保活」的勾，其余同上 |

关页面是测试的一部分：正式扩展在用户关掉小窗后，后台也要把回答写完。

## 5. 问题建议命中测试（可选，约 30 分钟）

诊断页底部点「问题建议命中测试页」。共 20 篇短材料，每篇里蓝色是假装你划选的文字。

1. 读材料，点「问」。
2. 在输入框写下**你真实会问的问题**，点「提交我的问题」。
3. 看出现的三条建议，选「都没有」或命中的那一条（意思相同即可）。

页面会自动记录时间，不用另外计时。做完点「复制 Markdown」，贴进回填表第 4 节。

## 6. 换一个浏览器再做一遍

Chrome 和 Edge 各做一遍第 1–4 步。如果方便，在公司 WiFi 和 VPN 两种网络下各做一遍快速测试。

## 7. 回填

每做完一组，点诊断页的「复制 Markdown」，贴进 `回填表.md` 对应位置。全部做完后把回填表发回。
